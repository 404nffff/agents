## 3. 链路脚本与数据规则

- 不要求新增单元测试；每个 P0 场景必须有可本地执行的 PHP 链路探针脚本。
- 链路探针脚本必须从 `skills/software-dev-process-zl/assets/zl_templete.php` 模板复制到 `docs/[需求目录]/[需求标识]_probe.php` 后改造：保留 `run($step)` 统一步骤入口、`step=all` 聚合逻辑和最终 JSON 出口；替换类名、业务依赖、payload 入参构造、`runStepN()` 真实链路调用和断言逻辑；禁止直接运行或交付模板原文件。
- 真实数据必须优先通过 `db-query` 只读查询组装，首次使用先执行 `--list-profiles`，并在本文档记录 profile 与查询摘要。
- 探针脚本、payload JSON、结果 JSON 均放入 `docs/[需求目录]/`。
