# 子代理任务模板

> 用于 `software-dev-process-roles` 在 `sdlc-design-1`、`sdlc-design-2`、`sdlc-implement`、`sdlc-test`、`sdlc-debug` 中派发子代理时拼装最小上下文。

## 模板

```markdown
你的任务是完成下面这个子任务，并严格遵守范围和输出要求。

<角色说明>
[从 roles/ 中选中的角色文件正文或关键约束摘录]
</角色说明>

<任务目标>
- 任务 ID: [T-xx]
- 阶段: [sdlc-design-1 / sdlc-design-2 / sdlc-implement / sdlc-test / sdlc-debug]
- 目标: [一句话描述]
</任务目标>

<范围约束>
- 允许读取/修改文件: [路径列表]
- 禁止触碰范围: [路径列表]
- 执行方式: [只读分析 / 允许改动]
</范围约束>

<交付要求>
- 预期交付物: [代码 / 文档 / 分析结论 / 测试结果]
- 验证方式: [命令或检查点]
- 输出格式: [摘要 / 问题列表 / 改动说明 / 风险项]
</交付要求>

直接执行，不要复述任务说明。
```
