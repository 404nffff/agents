# Lanhu Plan

用于“先读蓝湖原型，再输出执行文档”的场景。  
输出模板为本 skill 内置的通用模板，不依赖外部模板文件。

## 强制流程（不可跳过）

1. 先做链接入参检测（无链接立即提示并停止）
2. 检测通过后直接调用 `lanhu-mcp` 拉取页面数据
3. 按本 skill 的固定模板输出执行文档

## 0) 输入链接检测（必须）

必须先检查用户是否提供蓝湖原型链接（`lanhuapp.com` 或 `lanhu.cn`）。

判定规则：

- 已提供有效链接：直接进入 `lanhu-mcp` 调用阶段
- 未提供链接：必须立即提示用户输入链接并停止后续步骤

未提供链接时固定提示文案（原样输出）：

```text
请先提供蓝湖原型链接（例如 https://lanhuapp.com/... 或 https://lanhu.cn/...），收到链接后我再开始执行。
```

## 1) lanhu-mcp 调用要求

检测通过后，必须从 `lanhu-mcp` 获取以下信息：

1. 页面清单（A/B/C 或实际页面分组）
2. 每页 `text_only` 内容
3. 每页 `full + developer` 内容

要求：

- 仅使用用户提供的链接作为本次原型来源
- 先拉清单，再逐页拉详情
- 输出结论必须有原型证据，禁止凭空补全
- 若返回为空或字段缺失，必须在“风险与待确认项”中标注

- 不得省略上述一级章节。
