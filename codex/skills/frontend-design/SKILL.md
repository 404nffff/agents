本技能用于指导创建具有强辨识度、可用于生产环境的前端界面，避免通用“AI 套路感”审美。请实现真实可运行的代码，并对审美细节与创意选择保持极高标准。

用户会提供前端需求：需要构建的组件、页面、应用或界面。需求中可能包含用途、受众或技术约束等上下文信息。

## 设计思考

编码前先理解上下文，并确定一个明确且大胆的审美方向：
- **目标**：这个界面要解决什么问题？谁在使用它？
- **调性**：选择一个鲜明风格，例如极简冷峻、极繁混沌、复古未来、自然有机、奢华精致、玩具感趣味、杂志编辑风、野蛮主义、装饰艺术几何、柔和粉彩、工业实用等。可从这些方向获得灵感，但最终设计必须忠于所选审美。
- **约束**：技术要求（框架、性能、可访问性）。
- **差异化**：这个设计如何做到令人难忘？用户最终会记住哪一个点？

**关键要求**：选择清晰的概念方向并精准执行。大胆的极繁和克制的极简都可以，关键在于“有意识地设计”，而不是盲目堆砌强度。

然后实现可运行代码（HTML/CSS/JS、React、Vue 等），并满足：
- 可用于生产且功能完整
- 视觉冲击力强、记忆点明确
- 整体一致，具备清晰审美立场
- 细节经过精细打磨

## 前端审美指南

重点关注：
- **字体排印**：选择美观、独特、有性格的字体。避免 Arial、Inter 等过于通用的字体，优先使用能提升整体气质的字体组合；展示字体与正文字体应形成有层次的搭配。
- **色彩与主题**：坚持统一审美方向。用 CSS 变量保证一致性。主导色明确、点缀色有冲击力，通常优于均匀平淡的配色。
- **动效**：用动画构建效果与微交互。纯 HTML 项目优先 CSS 动画；React 项目可优先使用 Motion 库。聚焦高影响时刻：一次编排良好的入场动画（含分段延迟）通常优于零散的小动效。适当加入滚动触发与悬停惊喜。
- **空间构图**：尝试非传统布局，如非对称、重叠、斜向动线、打破栅格元素，或有意使用大留白/高密度排布。
- **背景与视觉细节**：不要默认纯色背景，要营造氛围与层次。加入符合整体风格的纹理与特效，例如渐变网格、噪点纹理、几何图案、分层透明、戏剧化阴影、装饰边框、自定义光标、颗粒叠层等。

严禁使用通用化 AI 审美模板：包括过度使用的字体族（Inter、Roboto、Arial、系统默认字体）、陈词滥调配色（尤其白底紫色渐变）、可预测的布局与组件套路，以及缺乏场景个性的模板化设计。

应进行创造性理解并做出符合语境的意外选择，让设计看起来真正“为该场景而生”。每次设计都应有差异，可在明暗主题、字体与视觉语言上主动变化。严禁在多次产出中收敛到同一套常见选择（例如反复使用 Space Grotesk）。

**重要**：实现复杂度必须匹配审美目标。极繁设计需要足够完整的代码与丰富动效；极简/精致设计需要克制、精准，并严格把控间距、排版与细微细节。优雅来自对视觉意图的高质量落地。

请记住：你具备卓越的创意实现能力。不要保守，充分跳出惯性思维，并对独特视觉方向进行彻底且高质量的执行。
